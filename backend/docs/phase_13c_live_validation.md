## 9. Partial Completion Behavior
When trajectories interact with boundaries or coastlines, the engine explicitly reports:
- `simulation_status`: `PARTIALLY_COMPLETED`
- `stranded_particle_count`: Number of particles deactivated.
- `completed_particle_count`: Number of particles successfully reaching the target time.
The frontend displays this as a "Plausible Release Region", and injects a visible warning into the limitations readout.

## 10. Landmask Findings
OpenDrift's internal GSHHG landmask effectively deactivates particles upon coastal stranding. In the Corsica scenario, this immediately truncates the backward trajectory, accurately representing the impossibility of origin paths tracing over the island.

## 11. Forcing Boundary Findings
The system checks for particles escaping the 0.5° (`+/- 1.5°` radius) Open-Meteo forcing window. If particles approach within `0.05°` of the border, they are flagged and the user is warned that grid expansion is recommended.

## 12. Scientific Limitations
- **Convex Hull Overestimation:** The geometric convex hull around a stranded/completed particle ensemble can overestimate the true origin region, particularly if particles split around islands.
- **Coarse Grid:** The 0.5° environmental grid is a prototype limit; actual coastal currents deflect around features smaller than this grid spacing.
- **Reverse Transport Assumptions:** Backward transport with deterministic environmental vectors does not fully account for chaotic diffusion and wind-wave mixing over time.
